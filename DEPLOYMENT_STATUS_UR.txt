Important known limitations:
- Signup sends a Firebase email-verification link, not a numeric email OTP. Numeric email OTP requires a configured email delivery provider and secret credentials.
- Parent notifications are in-app Firestore notifications; FCM push, SMS and external email notifications are not configured.
- Monthly dues are calculated only for fee structures explicitly configured with frequency=monthly and payments linked to feeStructureId and YYYY-MM period. Legacy/non-monthly structures require data normalization/configuration.
- Finance report is capped at 2,000 payments, 2,000 expenses, 3,000 students and 500 fee structures per run; it does not reconcile bank balances.
- Report-card generation is per student (optional exam filter), not a bulk class-wide publishing job.
- PDF output uses the browser print dialog (Save as PDF); thermal receipt output uses the 80mm print layout and the printer selected by the Admin.
- Android APK verification uses debug signing. Play Store release signing requires the owner's private upload key and is not included.

Release state: expanded release candidate, NOT yet 100% verified / production final.
No Firebase deploy is performed by --check. The --deploy mode deploys Functions, Firestore rules/indexes, Storage rules and Admin Hosting only after every local check passes.
